# 会費3年未納者の運用ガイド（手動運用）

**強制退会（自動・手動 expelled）の仕組みは廃止しました。**
3年滞納者の退会・削除は、滞納状況を確認したうえで **事務局が手動で対応** します。

- 自動退会 Cron（`/api/cron/membership-three-year-expulsion`）… 廃止・削除済み
- 手動強制退会 API（`/api/admin/members/[id]/expel`）… 廃止・削除済み
- 再入会メール退避 API／ボタン … 廃止・削除済み
- `status = 'expelled'` … 廃止（既存データは `expired` に統一。マイグレーション `024_remove_expelled_status.sql`）

---

## 1. 滞納状況の確認方法

滞納（未納）状況は引き続き確認できます。

- **会員一覧**（`/admin/members`）
  - 会員区分バッジ「**未納あり**」で未納者がわかります。
  - フィルタで「**未納あり**」「**3年連続未納**」に絞り込めます。
- **会員詳細**（`/admin/members/[id]`）
  - 直近3年度の「会費支払い状況」を表示。
  - 3年連続未納の可能性がある場合は警告バナーを表示します。
- **会費状況CSVエクスポート**
  - 「3年連続未納」列などで一括確認できます。CSS（口座振替）会員は入金登録漏れがないか合わせて確認してください。

---

## 2. 3年滞納者を退会させる場合（手動）

1. 上記で対象者を特定する（特に **CSS会員は入金登録漏れがないか**確認）。
2. 会員詳細の **「退会（資格喪失）」** を実行する。
   - プロフィール・入金履歴は**消えません**。資格（ステータス）を `expired` にし、ログイン用アカウントがあれば削除します。
3. データごと完全に削除したい場合は、Supabase の SQL Editor から手動で削除します（バックアップ推奨）。

---

## 3. 退会者を元に戻す場合（復活）

会員詳細の **「退会者を復活（有効化）」** から、`expired`（退会済み）の会員を `active` に戻せます。
ログイン用アカウントが無い場合は同じメールで紐付け、希望すればパスワード設定メールを送信します。

---

## 4. 補足

- `expelled_at` / `expulsion_reason` / `email_before_rejoin_release` 列は、旧データ・監査用に**物理削除せず残して**いますが、コードからは参照しません。
- 設計の詳細は `docs/会員データ簡素化_設計書.md` を参照してください。
